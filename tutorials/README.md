# Psy Stats Cog Neuro Tutorial 1 -- Basic Sampling and Statistical Inference in Python

An interactive Jupyter notebook introducing fundamental concepts in statistical inference using simulated cognitive experimental data.

The tutorial uses a hypothetical **visual detection task**, in which participants respond as quickly as possible when a visual stimulus appears on a screen. Reaction time, measured in milliseconds, provides an index of simple processing speed, encompassing sensory detection, response selection and motor execution. Similar paradigms are used in experimental psychology and cognitive neuroscience to investigate age-related differences in processing speed, attentional function and neurological impairment.

The simulated dataset represents 12,000 participants with a mean reaction time of 310 ms (SD = 45 ms). Through repeated random sampling, the tutorial explores sampling distributions, hypothesis testing, standard error, the central limit theorem and Student's *t*-distribution.

**Related cognitive assessments** include simple reaction-time tasks, choice reaction-time paradigms, the Deary–Liewald Reaction Time Task and the Psychomotor Vigilance Task (PVT). More complex measures of processing speed include the Digit Symbol Substitution Test (DSST) and Symbol Digit Modalities Test (SDMT), although these additionally recruit attention, associative learning and other cognitive processes.

**Requirements:** Python 3, NumPy, SciPy and Matplotlib.
